# Prototype Acceptance Tests

1. Playing/listening records exposure only; it does not mark a concept mastered.
2. Recognition evidence has lower weight than unaided production evidence.
3. Using a hint lowers evidence strength.
4. Delayed/self-generated production can strengthen evidence.
5. Favoriting content changes preference/library state but not mastery.
6. Weak concepts can remain due while the learner advances to new content.
7. Recommendations expose reason codes and can be reproduced from the same state.
8. Familiar speaker success does not alone create high listening confidence; transfer requires speaker/context variation.
9. Mature content never appears above the learner’s allowed content rating.
10. Learners can only read/write their own learner data under RLS.
11. Billing and entitlement rows cannot be written directly by authenticated clients.
12. The first lesson can be completed end-to-end on mobile-width layouts without horizontal overflow.
13. A newly confirmed learner cannot bypass onboarding until a learner profile has an onboarding completion timestamp.
14. Refreshing or leaving a lesson mid-session resumes from the stored stage without inventing extra mastery evidence.
15. Completing a lesson closes outstanding recommendations for that content.
16. Changing learner-facing feedback copy cannot change whether a stage is passed.
17. Spanish inverted punctuation does not cause a correct exact-text response to fail.
18. Content in language-QA/draft status is not learner-visible through the published-content path.
